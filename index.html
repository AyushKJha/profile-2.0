THE STORY BEHIND THE BUILD

Finding a rhythm that stuck.

THE START

A friend and I were struggling to stay disciplined with our work. We tried notes apps, habit trackers, and Excel spreadsheets, but none felt like a routine we could keep returning to.

THE BUILD

That frustration became the Daily Routine Tracker: one place for daily intentions, progress charts, and reflection. The current version keeps records on the device and supports portable backups.

THE IDEA

The aim is simple: make the next small action easier to see, and make progress easier to revisit.

THE STORY BEHIND THE BUILD

One car. Several ways to control it.

OPEN DEMO FOLDER ↗
THE START

The brief was to build an Android-controlled wireless car during a five-day college Skill Lab.

THE EXTENSIONS

Starting with Bluetooth control, I explored mobile voice commands and obstacle avoidance using an ultrasonic sensor on a rotating mechanism. The repository also includes distance measurement and range-scanning work.

THE TAKEAWAY

This was a hands-on introduction to connecting software commands with sensors, motors, and real-world movement.
