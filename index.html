01 / WEB & ANDROID APPLICATION

Daily Routine
Tracker.

A web and Android journal with up to 12 scheduled habits, automatic check-in saves, and weekly Excel/PDF reports. Optional encrypted workspaces keep records on the device; Android adds reminders and quiet hours.

DEVICE-LOCALYour data, with you.PORTABLEExcel, PDF & backups.

JAVASCRIPT · INDEXEDDB · WEB CRYPTO · ANDROID / JAVA

LIVE WEBSITE ↗SOURCE ↗ANDROID RELEASE ↗
THE STORY BEHIND THE BUILD

Finding a rhythm that stuck.

THE START

A friend and I were struggling to stay disciplined with our work. We tried notes apps, habit trackers, and Excel spreadsheets, but none felt like a routine we could keep returning to.

THE BUILD

That frustration became the Daily Routine Tracker: one place for daily intentions, progress charts, and reflection. The current version adds flexible routines, weekly charts, Excel and PDF reports, and optional encrypted workspaces while keeping journal records on the device.

THE IDEA

The aim is simple: make the next small action easier to see, and make progress easier to revisit.

02 / WEB & ANDROID APPLICATION

Fuel.
Better food decisions.

A meal journal that starts with a photo or a few words, then lets you correct the estimate before it becomes a record.

INPUTPhoto, text or barcode.CONTROLEdit portions and values.

NEXT.JS · TYPESCRIPT · SUPABASE · EXPO

OPEN APP ↗SOURCE ↗
THE STORY BEHIND THE BUILD

The estimate is a starting point.

THE NEED

Meal logging is less useful when an estimate cannot be corrected. Fuel was built around reviewing food quantities and package values before saving.

THE BUILD

Photo and text input feed an editable meal draft. Barcode lookup, daily totals, goals, recipes, and weight records bring the journal together across web and Android.

THE BOUNDARY

Nutrition estimates are approximate. Users should review serving sizes and product labels; the Android wrapper needs a connection for analysis and cloud records.

A clearer path.
With Orbit.

A conversational workspace for finding relevant jobs, reviewing fit, and preparing Gmail outreach. Every send requires approval of the exact draft.

DISCOVERYEvidence & fit analysis.CONTROLReview before sending.

NODE.JS · JAVASCRIPT · GMAIL OAUTH · OLLAMA

HOSTED PREVIEW ↗SOURCE ↗

THE THINKING BEHIND THE BUILD

From discovery to a considered next step.

THE PROBLEM

Job searching spans listings, application materials, outreach drafts, and replies. Orbit brings those steps into one conversational workspace.

THE APPROACH

Import a CV, inspect job evidence and fit, then review drafts and attachments before approving a send. Duplicate checks and reply tracking help keep the process organised.

THE CURRENT STAGE

A controlled hosted preview with isolated workspaces and configurable AI providers. Live AI tasks and a complete Gmail send/reply cycle are not yet verified in the repository’s documentation.

07 / LOCAL AGENT SYSTEM

ForgeRadar.
Ideas, examined.

A local agent workflow that turns community signals into proposals and owner-reviewed prototypes or persistent applications.

PROCESSScout → evaluate → build.REVIEWApproval before creating.

NODE.JS · OLLAMA · SQLITE

SOURCE ↗
THE STORY BEHIND THE BUILD

Before building, ask if it is worth building.

THE QUESTION

A popular discussion is not proof of a useful new product. ForgeRadar looks for unmet needs while checking existing solutions and uncertainty.

THE SYSTEM

Separate local roles collect evidence, evaluate ideas, critique novelty, propose scope, build, and run QA. The console shows actual handoffs and running stages.

THE LIMIT

It runs locally and new ideas await owner approval. A limited search cannot prove that no alternative exists, so every proposal still needs review.

Wishlist.
With structure.

A single-owner prototype for searching and organising saved items with persistent records and CSV/JSON import.

ORGANISETyped forms and search.PORTABLEImport and export records.

NODE.JS · SQLITE · JAVASCRIPT

SOURCE ↗
THE STORY BEHIND THE BUILD

Find a saved item without scrolling forever.

THE PROBLEM

Long wishlists become hard to browse when items cannot be filtered by category or sale context. The project starts with that practical friction.

THE BUILD

A local Node and SQLite application provides create, edit, delete, case-insensitive search, persistent records, and CSV/JSON import and export.
